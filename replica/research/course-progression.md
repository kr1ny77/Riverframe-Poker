# Последовательный курс NLHE — course-v1

Дата17.10.2026. Реализованные уроки организованы в7 разделов,8 наборов,43 устойчивых задания. Основа: [полная программа](advanced-poker-curriculum.md), фактические модели уроков и PracticeArchive schema5. Новые стратегические темы не публикуются этим этапом. Программа из4 уровней/14 модулей/40 уроков остаётся долгосрочным содержательным планом; счёт8/8 относится только к доступным наборам приложения.

Это педагогический маршрут текущих готовых наборов. Позиции математически можно изучать раньше; в данном маршруте они связывают уже знакомую equity с диапазонами. Предпосылки рекомендательные, все восемь наборов доступны для самостоятельного выбора. Блокеры содержат и базовый6/4/12, и более сложную часть с весами; будущий курс сможет выделить их в отдельные уровни после появления новых задач.

На карточке каждого набора видны предпосылки и их состояния, охват, количество ответов, число разных задач и последние оценки по задачам. В начале курса и после завершения любого набора есть следующий подходящий шаг. Если осталось непройденное, выбирается первый по каталогу набор с выполненными предпосылками. После охвата всех восьми при наличии рекомендации предлагается повтор; иначе показывается окончание реализованной части и необходимость новых примеров для переноса навыка.

Pot odds ранее открывал один из трёх готовых примеров. Теперь используется последовательность всех трёх прежних моделей:100/50 →25%;120/120 →33,3333…%;200/50 →16,6667…%. Математика прежняя. Ответ сохраняется до перехода к следующей задаче. Сбой записи оставляет разбор и retry; переход доступен после записи. Открытие/выход из урока не создаёт фиктивного результата.

## Завершение и точность

Пройденный набор означает, что на каждый обязательный устойчивый question key есть минимум один валидный сохранённый ответ. Ошибочный ответ также подтверждает прохождение задания; точность показывается отдельно. Это охват материала, а не аттестация навыка. Чтение вводной страницы и нажатие финальной кнопки сами по себе не отслеживаются; история хранит ответы. Охват может быть собран за несколько посещений.

Сравнение рук использует ключ шаблона из hcmp-v1-<template>-<mode>-<fingerprint>. Перестановка мастей и допустимая смена игроков сохраняют один шаблон;12 заданий не превращаются в24 независимых примера после смены мастей. Остальные наборы имеют фиксированные versioned ID. Все43 ключа берутся из текущего каталога.

Показываются отдельно:

- Число сохранённых допустимых ответов N.
- Число разных шаблонов K и охватK/requiredCount.
- Сколько последних ответов по каждому из K шаблонов верны.
- Окно последних20 ответов урока для рекомендаций и категорий ошибок.

Повтор одного вопроса увеличиваетN. Правильный последний ответ меняет текущую оценку этого шаблона; прежние ошибки сохраняются в истории. Ни процент по повторённым задачам, ни8/8 не доказывают перенос на новые доски, отложенное удержание или прибыль. Выигрыш фишек, игровые результаты и действия ботов в расчёт курса не передаются.

## Таксономия ошибок

Категория описывает, в каком задании был неверный ответ. Текущая история не содержит рассуждения ученика; точная психологическая/математическая причина из одного выбора не устанавливается.

| Сохранённый контекст | Категория |
|---|---|
| winner в обычном showdown | Сравнение комбинаций |
| template kicker/wheel/boardsplit | Кикер / младший стрит / ничья; специальные темы имеют приоритет |
| bestFive в остальных шаблонах | Выбор лучших пяти |
| flush-outs-next / river | Следующая карта / два открытия |

| position preflop/postflop/relative | Очередность действий |

Один неверный ответ относится к одной категории. В раскрываемой статистике урока показано errors/answers и число разных заданий для каждой категории с ошибками в окне20. Надпись не утверждает, что ученик обязательно перепутал конкретный знаменатель, проигнорировал ничьи или использует неправильную стратегию. Подробный разбор исходного урока остаётся источником объяснения.

## Правило повторения и выборка

Порог — **собственная продуктовая эвристика**, педагогическая эффективность не измерялась:

1. Последние максимум20 валидных ответов конкретного урока.
2. Минимум10 ответов и минимумmin(3, число обязательных шаблонов) разных заданий в этом окне.
3. Минимум3 неверных ответа и доля ошибок≥30% (проверяется целыми числами10×errors≥3×N).

До достаточного охвата показывается сообщение о накоплении ответов. При достаточной выборке и меньшем числе ошибок предлагается продолжать курс. При срабатывании — «Полезно повторить эти задания», с N/errors/K и явной пометкой эвристики. Повтор открывает соответствующий полный набор; выбор отдельной ошибочной задачи и календарное интервальное расписание пока не реализованы.

Проверочные границы:9 ответов/3 ошибки/3 задачи — рекомендации нет;10/3/3 — есть;10/2/3 — нет;20/5/3 — нет;20/6/3 — есть;100 повторов одной pot-odds задачи — рекомендации по правилу нет. Если20 старых ошибок сменились20 правильными ответами, окно даёт0 ошибок и рекомендация снимается. Для набора из2 задач достаточно охвата2, ноN≥10 сохраняется.

Повторные ответы коррелированы и могут отражать запоминание. Здесь не рассчитываются доверительный интервал навыка, рейтинг профессионализма или статистическая значимость. Малое число уникальных шаблонов указывается даже при большомN; рекомендации относятся к этим задачам.

## История и целостность данных

Новых полей хранения и миграции нет: используется прежняя schema5, все пять коллекций сохраняются. CourseObservation, CourseLessonProgress и LearningCourseSnapshot вычисляются из архива без записи файла. Сортировка по Date, при равных датах — порядок записи в массиве архива (исправление BUG-009). Последний сохранённый ответ одного урока сохраняет приоритет при совпадении дат. Неизвестные/неподтверждённые записи сохраняются в исходной истории, счёт исключённых записей виден в разделе курса.

Числовые записи принимаются в курс только по точному allowlist ID, совпадению correctPercent с каноническим значением и корректной оценке ответа. Для equity используются проверенные точные векторыv1 (907/990;50%;87,5%;62,5%); тест полного курса сверяет их с реальными расчётами существующих уроков. При чтении прогресса не выполняется тяжёлый перебор карт и не запускается симуляция.

Для сравнений рук проверяются валидность ответа, ключ/режим и канонический рисунок рангов/мастей шаблона с допустимой глобальной перестановкой мастей. Простая подмена template key при прежних картах исключается. Категориальные позиции/EV/блокеры используют прежнюю каноническую валидацию. UUID учитывается один раз. Сломанный файл отображает существующую ошибку загрузки; прежняя защита записи после failed reload сохранена.

## Границы реализации

Реализован маршрут имеющегося материала, а не полный профессиональный курс из40 уроков. MDF/bluff-catching, implied odds, размеры ставок, рейк/multiway, отдельный турнирный трекICM и профессиональные модели обозначены как планируемые. Прохождение существующих восьми наборов не обозначает их освоение.

Предпосылки и пороги повторения — учебные настройки. Стратегические диапазоны, EV и вероятности в отдельных уроках сохраняют собственные ограничения модели. Эвристика повторения не обозначается GTO. Сторонние таблицы, аналитика, серверы и зависимости этим этапом не добавляются.
