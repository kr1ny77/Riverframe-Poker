# Регрессия после добавления уроков — отчёт 18 октября 2026

Прогоны выполнены17 октября по временным меткам артефактов; результаты проверены и сводка завершена18 октября.

## Область и план

Текущая реализация: нативный NLHE, один игровой режим — шесть мест, Hero и пять локальных ботов. Отдельная игра с людьми в текущем проекте отсутствует. Восемь учебных наборов: комбинации, outs, pot odds, equity известной руки, позиции, equity диапазона, EV Call/Fold, блокеры. Визуальный дизайн сохраняется.

| ID | Проверка | Ожидаемый результат |
|---|---|---|

Автоматизация: `Tools/verify.sh`, `Tools/test-regression-ios.sh`, Swift Testing/Core/Application-checks и XCUITest. UI-драйвер создаёт собственный QA Simulator и удаляет его после завершения. Обёртки testRegression очищают тестовую историю через настройки перед каждым сценарием. Проверки ставок используют прежние QA fixtures; полная раздача использует обычных ботов.

## Обнаружено

BUG-009: равные временные метки сортировались по UUID; последняя оценка могла становиться прежней. Прямой пример с двумя ответами на pot odds и фиксированными UUID воспроизводит ошибку. Падающий тест сохранён в evidence/BUG-009-before.txt. Исправление ограничено порядком учебных наблюдений: дата, затем порядок записей архива. Для одного урока записи хранятся в одной коллекции; порядок между разными уроками на их показатели не влияет.

Первый UI-запуск regression-20261017-150504 остановлен ошибкой компиляции нового тестового setup (изоляция MainActor). Очистка перенесена в явно изолированные тестовые методы. Приёмочные UI-сценарии в этом запуске не выполнялись. Это диагностический запуск инструментария.

### Офлайн: точная граница доказательства

Пять разных процессов применили sandbox-профиль успешно; попытки внешнего и loopback TCP-соединения получили EPERM(errno1). При этих ограничениях завершился testRegressionOffline. На хосте контрольные подключения дали Network is unreachable и ошибку DNS; положительный контроль доступного Интернета на хосте отсутствует. Основание вывода о запрете приложения — применённый профиль и его собственные EPERM-пробы. Шесть других уроков проверены функционально в обычном Simulator; отдельный прогон всех восьми уроков при IP-изоляции остаётся задачей следующей приёмки.

### Оставшиеся границы

Физический iPhone, iOS17, VoiceOver/XXXL, смена системных часов и аварийное завершение в момент записи в этот прогон не входят. Повреждённый архив/отказ записи проверены на уровне настоящего Application-store; отдельная UI fault-injection сессия в этот регрессионный набор не включена. История outs проверена в общем архиве; отдельный UI-перезапуск сразу после outs в данном наборе отсутствует. Игра с людьми относится к отсутствующим возможностям текущего проекта. Новых открытых S1/S2 по выполненным сценариям нет; найденный S3 BUG-009 исправлен и проверен.
