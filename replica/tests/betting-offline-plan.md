## Воспроизводимые состояния

`POKER_QA_FIXTURE` читается только в Debug-сборке Simulator. Фикстуры используют существующие `HoldemGame(seed:42, startingStacks:…, button:0)` и публичный метод `act`; синтетические snapshot или изменённые правила не используются. Normal launch без QA-env сохраняет прежний путь создания игры. Боты после входа пользователя действуют штатно.

- `raise`: стандартные1000 фишек, UTG/HJ/CO call10, очередь герояBTN.
- `bet`: все call/check префлоп, пять check флопа, очередь героя.
- `short-stack`: герой15, остальные1000; три call перед героем.
- `short-call`: герой5, остальные1000; три call перед героем.
- `blind-all-in`: button4, геройBB; пять call перед героем, который уже внёс10 (банк60, стек990).
- `short-facing`: SB15, остальные1000; три call перед героем, hero call10, SB all-in15, BB/UTG/HJ/CO call, очередь героя.

## Способ офлайн-изоляции

Для выделенной QA-сборки host-инструмент `Tools/prepare-offline-profile.py` компилирует SBPL-профиль с `allow default` и запретом inbound/outbound IP. Debug Simulator-only QA-код применяет эти байты к текущему процессу через системный интерфейс sandbox. Эта тестовая процедура зависит от текущего ядра macOS; бинарный профиль заново компилируется на машине запуска. Он включается через Debug Simulator-only env `POKER_QA_NETWORK_DENY=1`; обычная сборка/запуск не получает этот режим. Обязательное доказательство — успешное применение профиля (`sandbox_result=0`) и фактический отказ TCP connect с EPERM/EACCES в приложении; изменение иконок Wi-Fi доказательством не считается. Хостовая сеть и пользовательские симуляторы сохраняют доступ.

Драйвер отдельно проверяет JSON-доказательства каждого изолированного запуска; при ошибке применения профиля или отсутствии реального EPERM/EACCES офлайн-приёмка не засчитывается. Итог выполнения и границы метода — в `betting-offline-results.md` и `report.md`.


## Контроль сети и границы метода

- `Tools/collect-offline-proof.py` после успешного UI-прогона копирует доказательства пяти отдельных запусков и отвергает результат при отсутствии sandbox-result0 или EPERM/EACCES. Данные берутся только из dedicated Poker QA Simulator, созданного драйвером.
- `Tools/SimulatorNetworkProbe.c` — отдельный QA-canary, который применяет тот же compiled policy и проверяет IPv4/IPv6 для TCP/UDP. В приложение он не линкуется.
- Ограничение действует на процесс тестируемого приложения; сеть macOS, runner и системные службы сохраняют свой режим. Иконка Wi-Fi на снимке может оставаться активной. Системный авиарежим на физическом iPhone остаётся отдельной проверкой.
- QA-ветки защищены `#if DEBUG && targetEnvironment(simulator)` и включаются явными launch environment. Обычный запуск использует существующую инициализацию игры; сборка для физического устройства/Release исключает эти ветки.
- Неудавшиеся варианты `sandbox_init` с компиляцией профиля внутри iOS runtime и перезапуск через host launcher не засчитаны как офлайн-результат. Их следы сохранены отдельно от итогового прогона.
