# Прогресс обучения и повторение: план регрессии

Статус: подготовлен для UI- и unit-проверок. Этот документ описывает проверяемые факты текущей задачи; результаты запуска фиксируются отдельным отчётом после завершения реализации.

## Границы

Курс и игровые виртуальные фишки хранятся отдельно. Сценарий использует только локальные данные `PracticeStore`, каталог `CourseCatalog` и нативный SwiftUI-интерфейс. Сеть, учётные записи и денежные операции в маршруте отсутствуют.

Тема `T03` выбрана как детерминированный UI-образец: `FoundationLesson` публикует несколько задач с этим `T-ID`; первая задача берётся из `CourseCatalog.foundations(for: .t03)`, а задача для ранней практики выбирается по отличающемуся стабильному `CatalogExerciseID`.

## Автоматические проверки

| ID | Уровень | Сценарий | Проверка |
| --- | --- | --- | --- |
| LP-01 | UI | Пустая история → неверный ответ T03 | Видны диагноз и показатель темы: одна попытка, одна уникальная задача. |
| LP-02 | UI | Ошибка T03 | Очередь содержит повтор T03 на следующий день; ссылка открывает другую задачу темы для ранней практики. |
| LP-03 | UI | Верный ответ на другой задаче T03 | Сохраняется второй результат и общий показатель отражает две попытки. |
| LP-04 | UI | Перезапуск после LP-03 | Общая метрика, очередь и диагностика T03 восстанавливаются из локального файла. |
| LP-05 | UI | Очистка: «Отмена» | Результаты и очередь остаются на месте. |
| LP-06 | UI | Очистка: «Очистить» | Показатель T03 возвращается к нулю, ссылка повторения исчезает. |
| LP-07 | Unit | Пустая история, неправильный ответ, интервалы 1/3/7/21 день | Логика создаёт тип ошибки, следующую дату и альтернативную задачу того же понятия. |
| LP-08 | Unit | Архив схем 1–7, повреждённый файл, отказ записи и retry | Миграция сохраняет UUID, даты и прошлые результаты; reload показывает ошибку; повтор записи использует тот же UUID. |

UI-сценарий находится в `AppUITests/CriticalFlows.swift` как `testLearningProgressAndReview`; запуск ограничен именем теста в `Tools/test-course-ios.sh`.

## Доступность и идентификаторы

Тест использует стабильные accessibility ID: `learning.metrics.total`, `learning.metrics.topic.T03`, `learning.metrics.level.<уровень>`, `learning.review.queue`, `learning.review.open.T03`, `learning.recommendation`, `learning.error.kind`, `learning.error.save`, `learning.error.saved`. Они ограничивают поиск элементов; доступные подписи задаются содержимым SwiftUI. Ручная расширенная VoiceOver/XXXL приёмка отложена пользователем.

## Ограничения измерений

Метрики малой истории отображаются с указанием размера выборки. Порог освоения из каталога служит проектным критерием курса. Он описывает состояние выполненных учебных задач и не характеризует силу игры или будущие результаты.

## Запуск

```sh
./Tools/test-course-ios.sh testLearningProgressAndReview
```

Перед запуском требуется завершённая интеграция экрана прогресса и локального хранилища. Проверки повреждённого файла, отказа записи и идемпотентного retry принадлежат unit-набору хранилища: UI-тест не создаёт намеренно повреждённые пользовательские данные.
