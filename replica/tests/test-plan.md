Матрица общих edge cases: empty/long/emoji проверяются для учебного ввода; double-submit и возврат — для ответов/ходов; relaunch — для прогресса. Даты сохраняются абсолютными Date; календарные streak/timezone/DST отсутствуют. Два окна/вкладки браузера, refresh, expired login, slow network, password, payment decline — N/A. Permission denied/corrupt file применяются к локальному хранилищу. UI restore активной раздачи и богатая история из архитектурного плана ещё не реализованы: фиксировать как разрыв план/прототип, а не утверждать проверенную поддержку.

Результаты и конкретное окружение записываются в report.md; каждый воспроизведённый дефект — bugs.md. Для исправления сначала сохраняется падающий тест, затем повторная проверка и полная регрессия.
