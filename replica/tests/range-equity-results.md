# Урок «Equity против диапазона»: реализация и проверка

Дата: 17 октября 2026. Область: учебный раздел NLHE и его числовой прогресс.

## Реализовано

Три фиксированных задания с Hero, доской и двумя физическими комбинациями соперника. До ответа видны карты и нормировка весов. После ответа — W/T/L и equity каждой ветви, точное число вычислений, взвешенные единицы и итог. Два последних задания используют одинаковые карты и противоположные веса. Состояния: ожидание/ошибка расчёта с повтором, проверенный ответ, ошибка записи с повтором тем же UUID, завершение. Расчёт находится в отдельном actor.

Формат, пределы, формулы и допущения: [range-equity-model.md](../research/range-equity-model.md). Метод — точный перебор; Монте-Карло отсутствует. Диапазоны — собственные иллюстративные условия без стратегических префлоп-чартов.

## Математика: выполненные точные проверки

| Сценарий | Реальные вычисления | Взвешенные W/T/L | Взвешенный знаменатель | Equity |
|---|---|---|---|---|
| Флоп A♠A♥ против K♠K♥:3, Q♠Q♥:1; 2♠7♥9♦ | 1980 = 2×990 | 3628 / 0 / 332 | 3960 | 907/990 ≈ 91,616161… % |
| Тёрн A♠K♥ против A♦K♣:1, 9♠9♥:3; T♠J♥Q♦2♣ | 88 = 2×44 | 132 / 44 / 0 | 176 | 7/8 = 87,5 % |
| Тот же тёрн, веса 3:1 | 88 | 44 / 132 / 0 | 176 | 5/8 = 62,5 % |

Тест `rangeEquityExactWeightedOracle` перечисляет отдельные ordered runouts для каждого физического opponent hand и вызывает независимый семикарточный `independentSevenCardRank`. Ветви и взвешенный итог совпали с production. Два последних ответа дополнительно закреплены аналитически: 25 %×50 %+75 %×100 %=87,5 % и 75 %×50 %+25 %×100 %=62,5 %. Рациональные доли точны, десятичные строки округлены.

`rangeEquityValidationScalingAndPersistence` проверяет: веса 0/−1/1001, пустой диапазон, девять рук, повтор пары в обратном порядке, совпадение с Hero/board, дубль внутри руки; отклонение до расчёта. Допустимы общие карты в разных альтернативных руках. Масштабирование весов ×10 сохраняет equity; диапазон из одной руки сводится к прежнему known-hand результату. Верный/неверный range-ответы сохраняются вместе с прежней known-hand историей, тема восстанавливается отдельно.

Полная регрессия: Swift Testing **23/23**, Core **24/24** (10 937 утверждений), generic iOS Simulator build и Application checks прошли. [Общий лог](../verification/range-equity-regression.txt). При подготовке тестов устранена неоднозначность вывода типа массива в Swift Testing macro; продуктовый расчёт прошёл проверку.

## Сохранение границ

Сохранены прежние schema 2 JSON и PracticeStore. Новая тема определяется versioned ID `equity-range-*-v1`; отдельные результаты отражаются существующим экраном прогресса. Сохраняются ответ, ключ, оценка, дата и ID фиксированного сценария. Свободные пользовательские диапазоны и сохранение их снимков потребуют нового контракта.

Cards, HoldemGame, GameViewModel и app entry сохранили прежние SHA-256: [preservation.json](../verification/range-equity-preservation.json). Движок игры и evaluator используют прежние исходники. Новых внешних зависимостей нет.

## Ограничения

Модель условна относительно списка рук и весов, один общий банк, два игрока, завершённые ставки. Никакая калибровка весов под реальное поле в этих задачах не выполнялась. Стратегические рекомендации, диапазон после линии, multiway, рейк и side pots требуют отдельных моделей. Свободный редактор и матрица отложены.

UI fault injection для нового экрана, VoiceOver-жесты, XXXL, физический iPhone, iOS17 и запрет IP-сети нового урока требуют отдельных проверок. Общие persistence fault-регрессии выполнены в Application checks.

Повтор: `./Tools/verify.sh`, затем `./Tools/test-range-equity-ios.sh`. Второй драйвер создаёт и удаляет собственный QA Simulator, сохраняя пользовательское устройство.
