# Проверка «Комбинаторика и блокеры»

Дата:17.10.2026. Версия blockers-v1. [Материал; алгоритм; источники и условия](../research/blockers-model.md).

## Точные проверки

- Все169 классов образуют непересекающееся разбиение1326 физических пар. Проверены6 парных /4 suited /12 offsuit комбинаций для каждого класса. Независимый oracle перебирает все52-choose-2, сравнивает baseline, afterHero и remaining для всех классов.
- Для каждого класса исключения уникальны, дополнение remaining+exclusions совпадает с исходным каталогом. Все указанные блокирующие карты действительно находятся в комбинации и на соответствующем этапе; комбинации этапа доски уже свободны от карт Hero.
- Векторы AA6→3→1, AKs4→2→1, AKo12→7→5 и точный список пяти AKo совпали. A♠A♥ исключается один раз на этапе Hero.
- Модель AA/KQs: с AsKd1value/3bluff→75%; веса3:1 дают массы3:3→50%; HeroQsQd даёт3value/2bluff→40%. Независимый оценщик подтвердил, что в этих river-примерах Hero выигрывает у разрешённых KQs и проигрывает AA. Перестановки Hero/доски/классов и общий масштаб весов сохраняют результат.
- Пустой разрешённый диапазон даёт nil для доли и отсутствие правильного процентного выбора. Отклонены ошибочные ранги/вид класса; неверные веса; дубликаты известных карт/классов; неизвестный questionID и индекс999. Все шесть ключей однозначны; целочисленная проверка процентов сохраняет точность.
- Schema1/2/3/4 реально читаются из JSON; исходные байты сохраняются до записи. Schema5 и compatibility-save сохраняют все пять категорий. Изменённые grade/index/ID; UUID из evCalls и отсутствие blockers в schema5 отклоняются без изменения повреждённых байтов.
- Application-store проверил все пять категорий; same-ID retry; reload; failed reload protection; clear; disk failure без фантомного результата и успешный повтор.

Полная регрессия: Swift Testing **32/32**, Core **24/24 группы;10 937 утверждений**, generic iOS Simulator build и Application checks прошли. Фокусный набор блока: **4/4**. Доказательства: [фокусный лог](../verification/blockers-unit.txt), [полная регрессия](../verification/blockers-regression.txt).

## Границы доказательства

Воспроизводятся точный состав колоды и условные вероятности при выбранных весах. Проверки не устанавливают правильность оценки реальных диапазонов или частоту блефов конкретного соперника. Новые доски; произвольные частичные диапазоны; веса отдельных мастей; адаптация по линии; card bunching; EV-решение и GTO требуют отдельной модели.

Физический iPhone; iOS17; реальное VoiceOver-прохождение; весь Dynamic Type и IP-изоляция этого экрана отдельно не проверялись. Disk failure проверен Application-store; отдельный UI fault injection не выполнялся. Внешние источники открываются через Link по нажатию. Модель считает локально без сетевых зависимостей.
