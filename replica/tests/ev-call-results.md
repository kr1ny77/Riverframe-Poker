# Приёмка урока EV колла и фолда

Дата: 17.10.2026. Материал ev-call-v1, только NLHE. [Модель, входы, формулы и источник](../research/ev-call-model.md).

## Выполненные расчёты

- Три заданных диапазона на одном ривере: 2W/0T/3L → equity40%, EVcall+30; 1W/0T/4L →20%, −10; 0W/1T/1L →25%, 0. EVfold=0 во всех случаях. Порог50/200=25%.
- Независимый оценщик семи карт подтвердил лучшие пятёрки Hero и каждой альтернативы соперника; отдельная сумма выплат +150/+50/−50 совпала с формулой equity×200−50. При нуле оба ответа принимаются. Проверен полностью ничейный диапазон: equity50%, EVcall+50.
- Отклонены недопустимые суммы, нечётный банк, неполная доска, пустой/дублированный диапазон, каждый конфликт карт диапазона с Hero/board и попытка подмены канонического задания по ID. Пределы сумм проверены на крупном нулевом примере без переполнения.
- Три фокусных Swift Testing функции прошли. В полной регрессии Swift Testing **28/28**, Core **24/24 группы, 10 937 утверждений**; generic iOS Simulator build и Application checks успешны.
- Archive schema4: реальные JSON schema1/2/3 читаются без изменения байтов; новая смешанная запись и compatibility-save сохраняют все четыре категории. Изменённая оценка, неизвестные ID/action, межкатегориальный UUID и schema4 без evCalls отклоняются с сохранением исходных байтов.
- PracticeStore: смешанные record, восстановление, same-ID retry, блокировка записи после failed reload, clear, disk failure без фантомного результата и успешный retry проверены Application tests.

## Условия и границы приёмки

Все рекомендации используют условный cash river диапазон BB после ставки, Hero BTN с оставшимся стеком50, P100/B50/C50, rake0/ante0 и единственный общий банк. Обоснование реального диапазона, EV ставок/рейзов, сложное дерево будущих улиц, ICM, multiway, side pots и нечётное распределение фишек требуют иных моделей. Результат конкретного вскрытия не моделируется; прогресс оценивает выбор по EV.

Физический iPhone, iOS17, все размеры текста и жестовое прохождение VoiceOver не проверялись. Сбой записи проверен на уровне настоящего Application-store; UI fault injection этого урока отдельно не выполнялся. Сетевая изоляция нового экрана отдельно не включалась; публичная ссылка открывается по нажатию пользователя.

XCUITest testEVCallLessonAndRelaunch: **1/1**, 0 failures/skips, 50,425 секунды; iPhone17e, iOS27.0 Simulator, Xcode27.1. Пройдены все три сценария. До ответа проверены банк100, колл50 и equity40/20/25%. Выбраны Call/Call/Fold: первый верный, второй намеренно неверный, третий верный при равенстве. Подтверждены +30/−10/0 в разборе, тексты рекомендаций, итог 2/3 и те же 2/3 после terminate/launch. Это исполнение текущей версии, с обычной сетью.
