# Компоненты «Учебной мастерской»

26 октября2026. Нативный SwiftUI, системная типографика и светлая/тёмная тема.
Канонические роли: App/Resources/design-tokens.json. Tools/build-design-colors.py
создаёт нативные named Color assets. CSS и веб-артефакты отсутствуют.

| Компонент | Композиция и роли | Состояния и доступность |
| --- | --- | --- |
| StudioHeading | Левый сильный SF-заголовок и краткая задача экрана | DynamicType, перенос без lineLimit, header trait |
| WorkbenchSection | Смысловой заголовок и открытая область содержимого | Интринсик-высота, область чтения ограничена по ширине |
| NavigationRow | Знак назначения, название, вторичная подпись и chevron | NativeNavigationLink; минимум48pt, VoiceOver-семантика |
| Primary/SecondaryButtonStyle | Тёплый главный action; спокойная вторичная поверхность | NativeButton, мгновенный pressed, disabled отдельно |
| PokerTableView | Два ряда мест вокруг полноширинного банка/board; Hero внизу | Наузком/крупномтексте board→Hero→раскрываемые соперники |
| SeatView | Имя/кнопка, позиция/стек, вклад и статус | Полная accessibility label, открытые карты из snapshot при вскрытии |
| PlayingCardView | Белая карта, крупный ранг и масть; компактный вариант | Ранг/масть через label; цвет дополняется символом |
| ActionBar | Пас/чек-колл в основной строке; ставка/all-in во второй | Отсутствующие действия исключены по LegalActions, подтверждение в sheet |
| BetEditor | NativeForm с диапазоном, raise-to, доплатой и быстрыми суммами | Точный ввод, invalid/focused/disabled; отмена и подтверждение |
| LessonFrame | Отдельная рамка цели, термина, метода или результата | Семантические подписи; Contrast усиливает контур |
| FoundationLessonView | Цель→ситуация→ввод; после проверки ответ и доказательство | Старое условие раскрывается; frozenUUID/save/retry сохраняются |
| FormulaSteps / диаграммы | Нативные строки вычисления, карты и точные числа | Полный текст и доступные подписи; цвет не единственный сигнал |
| LearningMetricsView | N/K, охват, первая точность и дата | Короткая сводка; объяснения/критерии раскрываются |
| LearningReviewQueueView | Срок, понятие и другая задача | Ранняя практика обозначена; ошибочная запись имеетretry |
| ErrorNotice | Значок предупреждения, текст причины и доступное восстановление рядом | Читается в обеихтемах, информативный label |
| SettingsView | Условия стола, общий профиль, данные на устройстве | NativeForm/Picker, выбранное значение, destructive confirmation |

Состояния: пустое, заполненное, выбранное, проверенное, ошибочное, сохранённое,
отказ записи, retry, завершение. Данные сцены и уроков получают прежние model/store.
Материалы прозрачного содержимого не используются для объяснения чисел.
NativeNavigationStack/TabView/sheet остаются единственным механизмом переходов.

Движение: смена числа открытых карт имеет локальный opacity-переход160мс по
кривой(0.23,1,0.32,1). ReduceMotion делает раскрытие статичным; данные и кнопки
готовы немедленно. Пауза/отмена ботов принадлежат прежней модели.
