# RiverFrame: три структурных концепции

26 октября2026. Нативное iOS17+, SwiftUI, iPhone. Каталог60/18/4,
226 заданий, прогрессJSON7; учебная практика с пятью локальными ботами.

## Наблюдения исходного интерфейса

Текущая композиция складывает равнозначные панели вертикально. В обучении рядом
стоят два следующих шага, повторение, полный маршрут восьми прежних наборов и
вводные правила. В теме до заданий повторяются несколько версий прогресса.
Экран результата продолжает тот же поток текста; действие и разбор имеют похожий
вес. На столе места представлены миниатюрными анкетами с картами, стеком,
позицией, вкладом и последним действием. Фактура и рамки добавляют ещё один слой.

| Before | After | Why |
| --- | --- | --- |
| Одинаковые панели для маршрута, правил и действия | Один текущий шаг и отдельный индекс курса | Следующее действие определяется с первого взгляда |
| Полный текст цели/метода/условия до вопроса | Цель, рабочая ситуация и раскрываемая справка | Начало урока требует меньше прокрутки |
| Мини-анкеты игроков вокруг банка | Короткие подписи мест, центральный board, отдельная зона Hero | Карты и цена решения получают собственные зоны |
| Прогресс перемешан с полной историей | Сводка, повторение, уровни, история по запросу | Обзор и подробности имеют разную плотность |
| Повсюду тёмные панели, золото и крупные скругления | Светлая учебная поверхность и отдельная сцена стола | Смысловые режимы видны композиционно |

## A. Учебная мастерская — выбранная концепция

Характер: спокойная точность. Содержание выглядит как рабочая поверхность для
разбора решения. Связующий мотив — выделенная зона ситуации и компактная строка
её параметров. Типографика SF: сильный заголовок, обычный текст, табличные цифры.
Прямоугольные группировки имеют разный масштаб по функции: поле ситуации,
строка навигации, маленькая карта, полноценная сцена стола.

Роли светлой темы: canvas #F2F5F8, sheet #FFFFFF, ink #172C3D, muted #526373,
primary #A74D24, felt #1E5057. Тёмная тема: canvas #15232D, sheet #20323E,
ink #F1F5F7, muted #B8C8D2, primary #F2B189; felt остаётся отдельной сценой.

Главная: приветствие RiverFrame и короткая фраза; одна широкая горизонтальная
сцена практики с миниатюрной доской, затем конкретное продолжение учёбы,
ссылка в весь курс и компактный след последней проверки. Условные параметры
стола видны до входа. Настройки остаются привычным отдельным разделом.

Стол: верхняя пара мест, боковые пары, центральная линия board/банк, внизу
широкая полоса Hero. Места с закрытыми картами дают имя/позицию/стек и краткий
статус. Частые действия находятся в отдельном доке. При крупном тексте стол
превращается в последовательность: board → Hero → соперники; действия доступны
в прокрутке. Неполная ставка, all-in и отмена используют существующие команды.

Урок: короткая цель → явный переход к ситуации → поле условия и вопрос → ввод →
отдельная область проверки и пошагового разбора. Термин и метод доступны как
отдельные рамки. Объяснения сохраняются, вторичные детали раскрываются.

```
Главная                 Стол                     Урок
RiverFrame              места 3/4/5              T-ID / цель
[стол + начать]         места 2   board   6       [ситуация / числа]
Продолжить тему         Hero + две карты          вопрос / ввод
Курс / последняя дата   [пас / колл / ставка]    [проверить]
```

## B. Аналитическая консоль

Характер: компактное рабочее место продвинутого ученика. Палитра: canvas #17242A,
панель #24383E, основной текст #F0F4F3, вторичный #B9CBCB, сигнал #E4AB65.
SF semibold для заголовков, табличные цифры для параметров; плотная сетка8pt.

Главная — журнал последних решений и компактная командная строка игры/курса.
Стол — горизонтальные полосы позиций, board как часть ledger, постоянно видимые
числа банка/колла/вкладов. Урок — карточка входов слева/сверху, вычисление и
проверка справа/снизу; детали разворачиваются на той же рабочей поверхности.

```
Главная                 Стол                     Урок
Последние решения       места / очередь          входы / метод
[курс] [стол]           board / ставки           формула / ответ
журнал                  ledger / Hero            ветви / проверка
```

Сильная сторона — высокая плотность при разборе. Ограничение — новичку требуется
больше усилий для выделения первого шага и различения терминов.

## C. Карточный маршрут

Характер: последовательная короткая тренировка с большим пространством.
Палитра: canvas #ECEFE8, карточка #FFFFFF, ink #26362E, muted #5D6C61,
акцент #995033, игровая поверхность #374F42. Крупные SF Rounded заголовки,
обычный SF в вопросах; каждый экран посвящён одному состоянию.

Главная — одна текущая учебная карточка с соседней карточкой практики.
Курс — перелистываемые модули, после выбора обычный список тем.
Стол — большая стадионная сцена, служебные данные под раскрываемым заголовком.
Урок — цель/ситуация/ответ/разбор как отдельные шаги с текстовыми кнопками
перехода; перескок к полному условию всегда доступен.

```
Главная                 Стол                     Урок
Текущая карточка        [широкая сцена]           шаг / ситуация
[продолжить]            Hero / цена               один вопрос
следующий модуль        панель действий           следующий шаг
```

Сильная сторона — фокус. Ограничение — сравнение исходных чисел с разбором
требует возвратов между шагами; полный курс превращается в длинную последовательность.

## Выбор и контракт реализации

Выбрана A: одновременно поддерживает быстрый ход, чтение длинного разбора и
возврат к конкретной теме. Информационная плотность зависит от задачи: обзор
главной, компактный стол, спокойный урок, подробный журнал по запросу.
Профиль design-swiftui-interfaces — standard с выраженной предметной композицией.

Сохраняются NavigationStack/TabView, sheet редактора, все существующие назначения
и идентификаторы учебных задач. Владельцы game/store и модели данных прежние.
Графика карт, чисел и схем строится SwiftUI. Новая растровая графика не требуется.
Для частых действий — немедленная подсветка. Системные переходы показывают
иерархию; открытие карты — короткая связанная обратная связь с Reduce Motion.

Приёмка: те же ключевые экраны до/после; iPhone17e и малыйSE, большой DynamicType,
светлая/тёмная тема, контраст, уменьшение движения/прозрачности, VoiceOver-семантика,
ошибки и длинное условие. Успешные доменные тесты и сохранённые старые данные
обязательны. Сводный отчёт: final-review.md.
